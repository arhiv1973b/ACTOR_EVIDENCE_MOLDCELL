# ⚖ A©tor Declaration: Moldcell Evidence Repository

Локальное хранилище доказательной базы (Jus Cogens, Erga Omnes) по делу против Moldcell и судьи Додон. 
Все бинарные файлы (PDF) управляются через Git LFS и интегрируются в многоузловой DAG-манифест TI-ULA через хэши SHA-256.

## Структура LFS-узла
- `/docs` — исходные PDF-файлы (исполнительные листы, ответы Moldcell, исковые заявления).
